# Extended Min for Visual Studio Code

Syntax highlighting, comment toggling, auto-indent, and indentation-based folding for Extended Min (`*.xmin`) files.

The `extended-min` extension folder contains:

- `syntaxes/xmin.tmLanguage.json`: TextMate grammar
- `language-configuration.json`: `#` line comments (Cmd+/), bracket and quote pairing, indent after `if` / `elif` / `else` / `while` / `def`, and indentation-based folding
- `package.json`: registers the `xmin` language for `*.xmin` files and defaults to 2-space indentation with spaces

The grammar uses the same scope names as the [Sublime Text package](../sublime-text/), so the scope table in that README applies here too. Scope names follow the Python grammar where Extended Min has an equivalent, so Python-oriented themes color most of the language. Every kind of punctuation has its own scope.

## Install

Run these commands from the repository root. Each one links the extension into VS Code's extensions folder, so later changes in the repo take effect after a reload. The link name must be `michaelkamprath.extended-min-0.1.0` (`<publisher>.<name>-<version>` from `package.json`).

macOS and Linux:

```bash
ln -s "$PWD/editors/vscode/extended-min" \
  "$HOME/.vscode/extensions/michaelkamprath.extended-min-0.1.0"
```

Windows (PowerShell; creating a symbolic link needs Developer Mode or an administrator shell):

```powershell
New-Item -ItemType SymbolicLink `
  -Path "$env:USERPROFILE\.vscode\extensions\michaelkamprath.extended-min-0.1.0" `
  -Target "$PWD\editors\vscode\extended-min"
```

You can copy the `extended-min` folder to that path instead, but a copy does not pick up later changes. For VS Code Insiders, use `.vscode-insiders/extensions`.

Then restart VS Code, or run "Developer: Reload Window" from the Command Palette. `*.xmin` files open as Extended Min; the status bar shows the language. To inspect scopes, run "Developer: Inspect Editor Tokens and Scopes" on any token.

To uninstall, delete the `michaelkamprath.extended-min-0.1.0` entry from the extensions folder and reload. Deleting the link leaves the repo files in place.

## Customizing colors

To color individual scopes, add rules to `settings.json`:

```json
"editor.tokenColorCustomizations": {
  "textMateRules": [
    { "scope": "punctuation.separator.slice.xmin", "settings": { "foreground": "#d19a66" } },
    { "scope": "keyword.operator.concatenation.xmin", "settings": { "foreground": "#c678dd" } }
  ]
}
```

## Editing the grammar

`syntaxes/xmin.tmLanguage.json` is generated by `gen_grammar.py`, which also checks that every regex compiles and every include resolves:

```bash
python3 editors/vscode/gen_grammar.py editors/vscode/extended-min/syntaxes/xmin.tmLanguage.json
```

Change the generator rather than the JSON, and keep it in step with the Sublime syntax. The keyword set mirrors the interpreter's tokenizer keyword table (`extended-min.min64x4`).
